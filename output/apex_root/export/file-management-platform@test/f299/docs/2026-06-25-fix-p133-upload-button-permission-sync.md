# P133 上传按钮权限同步修复

## 背景

- 现象：文件夹管理员进入部分目录时，`新建文件夹` 按钮可见，但 `上传文件` 按钮偶发不可见。
- 影响页：`P133` 文件库。

## 原因分析

- `新建文件夹` 使用 `p133CanCreateFolder()`，其条件为根层级或当前目录有管理权限。
- `上传文件` 使用 `p133HasManagePermission()`，完全依赖隐藏项 `P133_DISPLAY / P133_ROOT_DISPLAY`。
- 目录切换后，权限隐藏项由动态动作异步刷新；工具栏若先渲染、后更新权限值，就会出现按钮状态滞后。
- 因此会出现同一目录内“有时能看到上传按钮、有时看不到”的时序问题。

## 本次修复

- 在 `P133` 前端初始化逻辑中增加对以下隐藏项的 `change` 监听：
  - `P133_DISPLAY`
  - `P133_ROOT_DISPLAY`
  - `P133_PARENT_FOLDER_ID`
  - `P133_FILE_LEVEL`
- 任一值变化后，重新调度 `p133ScheduleViewSync()`，确保工具栏在权限值更新后再次同步显示状态。

## 验证重点

- 从根目录进入有管理权限的子目录后，`上传文件` 与 `新建文件夹` 应同时正确显示。
- 在无管理权限目录中，`上传文件` 应继续隐藏。
- 目录切换、IG 刷新、面包屑返回后，按钮状态应保持一致。
