## 本次范围

- 在 `P133` 列表视图中接入 IG 拖拽排序。
- 用 `SORT_NUM` 替代原“大小”列，作为排序列。
- 增加“默认”排序模式（内部仍使用 `MANUAL` 值），并通过 on-demand 过程持久化当前目录 siblings 的顺序。
- 拖拽权限口径：
  - 只要用户对当前文件夹有管理权限，即可对该文件夹下内容拖拽排序；
  - 不再逐个判断每个文件的管理权限。
- 排序保存口径：
  - 仅更新 `FMP_FILE.SORT_NUM`；
  - 不更新“更新人 / 更新时间”。
- 排序范围口径：
  - `SORT_NUM` 只在当前文件夹内独立编号；
  - 文件或文件夹移动后，源文件夹与目标文件夹都要分别重排，避免跨目录共用序号。
- 拖拽前端口径：
  - IG 若存在 frozen pane，以用户当前可见的排序列作为拖拽入口；
  - 实际保存顺序仍只按当前目录同级记录计算。
- 调整 `P133` 顶部操作按钮权限：
  - 非管理权限用户单选时，保留“分享”和“权限查看”；
  - 重命名、移动、删除仍要求管理权限。
- 调整 `P156`：
  - 无管理权限时进入只读查看模式；
  - 禁用修改相关按钮；
  - 页面标题展示为“权限查看”。
