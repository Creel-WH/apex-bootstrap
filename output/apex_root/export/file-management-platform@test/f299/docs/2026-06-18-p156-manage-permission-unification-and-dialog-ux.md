# 2026-06-18 P156 管理权限统一与弹窗体验优化

## 背景

- 目标页面为 `P156 权限设置`。
- 本次按解释 A 执行，将“添加协助者权限”统一解释为当前对象的 `manage` 权限。

## 目标

1. 无 `manage` 权限时隐藏“添加协助者”按钮。
2. 无 `manage` 权限时禁用协助者权限调整下拉。
3. 无 `manage` 权限时禁用分享范围修改。
4. 优化 `P156` 模态页在展开权限菜单时的宽高表现，避免弹窗被撑大变形。

## 影响范围

- 页面：`P156`
- 数据对象：
  - `FMP_FILE`
  - `FMP_SCOPE`
  - `FMP_USER`
  - `BASIC_JA_DING_USER`
  - `BASIC_JA_DING_DEPT_USER`

## 实施说明

- 在 `P156_PERMISSION_BOOTSTRAP` 与 `P156_PERMISSION_GET` 中回传统一的 `canManage` 状态。
- 前端只按 `canManage` 控制新增协助者、移除、权限调整、分享范围、保存和恢复继承。
- 调整模态页布局为弹窗内滚动，并约束协助者权限浮层高度，减少弹窗变形。

## 验证目标

1. 有 `manage` 权限的用户可正常新增协助者、调整权限、修改分享范围、保存和恢复继承。
2. 无 `manage` 权限的用户仍可查看当前权限信息，但不能进行上述修改操作。
3. 展开协助者权限菜单时，`P156` 弹窗不再被明显撑高或变形。
