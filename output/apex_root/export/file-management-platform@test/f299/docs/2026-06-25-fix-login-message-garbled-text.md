# 登录页乱码提示修复

## 背景

- 现象：登录页部分提示文案显示乱码。
- 范围：`f299` 文件管理平台登录链路。

## 原因

- 登录认证函数 `FMP_APEX_LOGIN` 中直接写入了 3 条乱码的 `apex_error.add_error` 提示。
- 登录后置过程 `FMP_LOGIN_SUCCESS` 的 `NO_DATA_FOUND` 分支中也有 1 条同类乱码提示。
- 这些提示会直接回显到登录页通知区，因此用户能看到乱码。

## 本次修复

- 修正 `FMP_APEX_LOGIN` 中以下提示：
  - `密码错误，请检查后输入`
  - `账号不存在或已离职，请检查后输入`
  - `系统异常，请联系管理员`
- 修正 `FMP_LOGIN_SUCCESS` 中以下提示：
  - `账号不存在或已离职，请检查后输入`

## 排查结果

- 当前 `f299` 运行时相关源码中，已未检出上述同类登录提示乱码残留。
- 仍存在少量历史文档中的乱码，但不影响应用运行时页面提示。

## 验证

- 已在 `file-management-platform@test` 编译：
  - `FMP_APEX_LOGIN`
  - `FMP_LOGIN_SUCCESS`
- 编译结果：`No errors`
