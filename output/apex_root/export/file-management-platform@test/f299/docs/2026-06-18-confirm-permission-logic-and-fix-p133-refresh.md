# 2026-06-18 确认权限业务逻辑并修复 P133 刷新

## 背景

- 当前 `f299` 已完成登录改造、页面管理改造以及权限相关 `STS_* -> FMP_*` 切换的一部分工作。
- 本次需求需要两类动作：
  1. 对当前权限业务逻辑做一次逐条确认，判断现状是否符合业务口径；
  2. 修复 `P133` 文件库页刷新按钮点击无效的问题。

## 本次需确认的业务口径

1. 所有用户都可以登录系统，用户信息来自统一人员主数据。
2. 登录后的用户可以在所有子平台中切换。
3. 登录时默认展示用户上一次访问的平台。
4. 用户可以看到任意平台的文件库列表。
5. 只有至少具备查看权限时，才能点开文件或文件夹详情。
6. 若无相关权限，则用户能看到文件列表，但无法查看文件详情。
7. 文件权限由该文件具备可管理权限的人授予。
8. 下级文件默认继承上级文件权限。
9. 若手动变更了文件权限，则该对象不再继续继承后续上级权限变化，但默认保留变更前已继承到的权限。
10. 用户身份只需命中人员或部门其中之一即可获得对应权限，且权限由大到小覆盖。
11. 修复 `P133` 刷新按钮点击无效问题。

## 当前实现对应关系

### 登录与平台切换

- 登录页：`P9999`
- 当前认证函数：`db/functions/fmp_apex_login.sql`

  - `shared_components/logic/application_processes/set_current_system.sql`
  - `page_00000.sql` 中同名 on-demand 过程

#### 现状判断

- “所有用户可登录”：
  - 现状基本满足，`FMP_APEX_LOGIN` 直接校验 `BASIC_JA_DING_USER` 中未离职用户。
- “可在所有子平台中切换”：
  - 现状满足，`GET_SYSTEM_OPTIONS` 直接返回所有 `STS_SYSTEM` 中启用的平台。
- “默认展示上一次访问的平台”：
  - 现状不满足。
  - 当前只把选择结果写入会话 `SYSTEM_ID`，未见持久化“上一次访问平台”的用户级记录，也未在登录成功后恢复历史平台。

#### 现状判断

- “可以看到任意平台的文件库列表”：
  - 现状部分满足，`P133` 根层受页面管理与菜单显示控制，但对象明细查询里并没有把“无权限对象全部过滤掉”。
- “只有至少具备查看权限时，才能点开详情”：
  - 现状需要进一步核对 `P133` 点击进入详情/预览/下载/打开文件的前端和后端校验链。

- “无相关权限时可见列表但不可查看详情”：
  - 现状存在靠近该口径的实现方向，但还未完成最终确认。

### 文件权限授予与继承

- 主要页面：`P156`
- 主要对象：
  - `FMP_SCOPE`
  - `FMP_FILE`

#### 现状判断

- “文件权限由具备可管理权限的人授予”：
  - `P156` 当前围绕 `MANAGE / VIEW_DOWN / VIEW` 管理协作者，方向一致；
  - 但授予动作前的“当前操作者必须具备 manage”还需要补查 `P133 -> P156` 的入口控制和 `P156_PERMISSION_SAVE` 的服务端保护。
- “下级默认继承上级权限”：
  - 现状满足，`P156` 读取逻辑里存在 `INHERITED`、`ROOT_MANAGER`、`restricted` 分支。
- “手动变更后不再继续继承上级后续变化，但保留变更前权限”：
  - 现状基本满足，`FMP_FILE.IS_PERMISSION_CHANGES` 已用于区分是否继续继承；
  - `P156_PERMISSION_SAVE`/`P156_PERMISSION_RESET` 中对当前对象和子级的 `FMP_SCOPE`/`scope_type` 处理已体现“断开继承”与“恢复继承”。

### 用户或部门任一命中即可获得权限，且大权限覆盖小权限

- 主要页面：`P156`
- 主要对象：`FMP_SCOPE`

#### 现状判断

- 现状基本满足。
- `P156` 读取权限时同时处理：
  - `range_type = 'USER'`
  - `range_type = 'DEPT'`
- 排序与聚合上也体现了：
  - `manage > download > view`

- `P133` 中刷新按钮事件位于 `page_00133.sql`
- 已确认存在以下代码路径：
  - `p133RefreshContent()`

- 当前刷新事件已绑定，但很可能只覆盖了 IG 场景，未覆盖当前视图状态或工具栏重绘后的按钮实例；
- 需要结合 `P133` 当前“列表视图 / 网格视图 / 内容区 region 名称 / toolbar 重建逻辑”一起修。
