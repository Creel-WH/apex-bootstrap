# P156 权限设置 / 权限查看

## Purpose

- 用于查看或维护文件 / 文件夹的分享范围与协作者权限。

## Current Behavior

- 页面以模态页方式打开。
- 顶部展示当前对象权限页标题：
  - 有管理权限时，保持原可编辑权限页行为；
  - 无管理权限时，页面标题显示为“权限查看”。
- 协作者按权限分组展示：
  - `可管理`
  - `可查看和下载`
  - `仅可查看`
- 具备 `manage` 权限时，允许：
  - 添加协作者；
  - 移除协作者；
  - 调整协作者角色；
  - 修改分享范围；
  - 保存权限；
  - 恢复继承。
- 不具备 `manage` 权限时：
  - 修改类按钮保持只读 / 禁用；
  - 协作者权限下拉不可编辑；
  - 分享范围不可修改；
  - 页面用于查看现有权限信息。

## Related Data

- 主体文件：`FMP_FILE`
- 权限范围：`FMP_SCOPE`
- 部门来源：`BASIC_JA_DING_DEPT`
- 人员来源：`BASIC_USER`、`BASIC_JA_DING_USER`
