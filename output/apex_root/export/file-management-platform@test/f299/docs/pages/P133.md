# P133 文件库

## 2026-06-30 按钮动作小函数化

- 删除按钮动作聚合入口 `p133RunAction(...)` / `window.p133RunActionImpl`，避免 toolbar 按钮、行内按钮和行菜单继续共用一个大分发器。
- 新增动作级函数：`p133ActionShareSelected()`、`p133ActionRenameSelected()`、`p133ActionMoveSelected()`、`p133ActionSettingsSelected()`、`p133ActionDeleteSelected()`。
- `P133_ACTION_SHARE`、`P133_ACTION_RENAME`、`P133_ACTION_MOVE`、`P133_ACTION_SETTINGS`、`P133_ACTION_DELETE` Dynamic Action 直接调用对应动作级函数。
- 动作级函数在全局 `p_javascript_code` 中保留 wrapper，实际实现挂到 `window.p133Action*SelectedImpl`，避免 APEX Dynamic Action 在全局上下文执行时找不到 onload 作用域内函数。
- 行内按钮和行菜单仍以 `p133RunSingleAction(actionName, fileId, fileType)` 作为入口；该入口只负责设置单行选中态并同步 UI，然后调用对应动作级函数，不模拟 toolbar 按钮点击。
- 选中态校验、单选校验、管理权限校验收敛到 `p133RequireSelectedAction(...)`，并继续复用 `p133SelectionCanManage`、`p133OpenPermissionDialog`、`p133RedirectToRename`、`p133RedirectToMove`、`p133DeleteSelection` 等底层 helper。
- 列表 / 网格切换按钮的 Dynamic Action 直接写入 `sessionStorage` 并调用 `p133SyncView()`；页面级 `p133SetViewMode(...)` 已移除。

## 2026-06-30 按钮区二次收敛

- 删除上一版新增的重复可见按钮 `p133_btn_upload`、`p133_btn_create_folder`，复用既有 APEX Page Button `btn_upload`、`btn_create_folder` 作为上传文件和新建文件夹入口。
- `btn_upload`、`btn_create_folder` 保持原动态动作触发关系，仅补齐 Text with Icon 模板、图标和当前工具栏样式类；权限显隐仍由当前目录管理权限驱动。
- 列表视图 / 网格视图按钮使用 Universal Theme Button Set 模板选项：`t-Button--pillStart`、`t-Button--pillEnd`，保留当前激活态视觉。
- 选中项后的分享、重命名、移动到、权限设置、删除按钮仍为 APEX Page Button，运行时移动到 `p133-selection-panel` 内，与“已选中 N 项”共用浅蓝背景和线框。

## 2026-06-30 按钮动态操作补齐

- `p133_btn_share`、`p133_btn_rename`、`p133_btn_move`、`p133_btn_settings`、`p133_btn_delete` 补齐真实 APEX Dynamic Action，动作分别调用 `p133Action*Selected()`。
- `p133_btn_view_list`、`p133_btn_view_grid` 补齐真实 APEX Dynamic Action，动作直接写入当前视图模式并调用 `p133SyncView()`。
- `p133_btn_refresh` 拆成两个带条件的 Dynamic Action：列表视图使用 APEX 原生 `Refresh` 刷新 `content` region；网格视图使用 APEX 原生 `Refresh` 刷新 `p133_cards` region。
- 页面级 `p133InitViewModeImpl` 不再绑定这些按钮的 click 行为，仅保留排序菜单、行菜单、卡片选择等仍由自定义 DOM 驱动的事件绑定。

## Purpose

- 作为 `f299` 文件库统一入口页，支持目录浏览、文件打开和批量操作。
- 在同一页面内提供列表视图与网格视图切换。

## Current Behavior

- 页面顶部保留 `上传文件`、`新建文件夹` 等主操作入口。
- 列表内容按当前会话 `SYSTEM_ID` 过滤，只展示当前子平台下的数据。
- 列表视图基于 Interactive Grid region `content`。
- 网格视图基于 APEX Cards Region `p133_cards` 渲染。
- 排序菜单支持：
  - `默认`
  - `文件名`
  - `更新时间从近到远`
  - `更新时间从远到近`
  - `创建时间从近到远`
  - `创建时间从远到近`
- `SORT_NUM` 只在手动排序场景展示：
  - 非默认排序时隐藏；
  - 默认排序时显示；
  - 原“大小”列已移除。
- 当满足以下条件时支持拖拽排序：
  - 当前为列表视图；
  - 当前排序方式为 `默认`；
  - 当前文件夹具备管理权限。
- 拖拽排序通过页面 on-demand 过程 `SAVE_FILE_LIBRARY_ORDER` 持久化到 `FMP_FILE.SORT_NUM`。
- 拖拽保存只更新 `SORT_NUM`，不改动“更新人 / 更新时间”。
- 选中条目后的操作按钮按权限控制：
  - 有管理权限时，可执行分享、重命名、移动、权限设置、删除等操作；
  - 无管理权限但单选文件或文件夹时，可执行只读类操作；
  - 多选且包含无管理权限对象时，不开放改动类操作。

## Interaction Notes

- 手动拖拽只影响当前目录下的同级数据，不影响其他目录。
- IG 刷新、翻页后会重新初始化拖拽绑定。
- 文件或文件夹移动后，会分别重排源目录和目标目录下的 `SORT_NUM`。
- 列表视图中，文件或文件夹改为双击进入，不再单击进入。
- 列表视图中，行选中只允许通过行选择器勾选，不再通过点击整行切换。
- 新建文件夹、上传文件、预览、重命名、移动、权限设置等跳转不再通过 `P133_PAGE` 隐藏项中转；依赖当前目录或选中对象的操作在点击时通过 `P133_GET_ACTION_URL` 生成 checksum-safe URL。
- 移动操作通过 `apex.navigation.dialog(apex.util.makeApplicationUrl(...))` 打开 `P155`，避免旧版弹窗渲染错误。
- 切换离开默认排序时隐藏 `SORT_NUM`，切回默认排序时恢复显示。
