# P0 全局页

## 用途
- 承载 `f299` 全局头部样式、子平台切换、以及跨页面复用的前端初始化逻辑。

## 当前行为
- 右上角头部使用 APEX 模板自带的 `BEFORE_NAVIGATION_BAR` 占位区渲染子平台切换控件。
- 子平台切换控件使用 APEX 原生 `Select List` 页面项 `P0_SYSTEM_SWITCH`，位置在用户名下拉左侧。
- 页面加载后通过 `GET_SYSTEM_OPTIONS` 同步当前 `SYSTEM_ID` 到 `P0_SYSTEM_SWITCH`，避免显示旧会话值。
- 切换子平台时调用共享 application process `SET_CURRENT_SYSTEM`，由服务端统一清理 `P133` 会话状态，并跳转到带 `SESSION` checksum 的当前页 URL。
- 不再在前端切换回调里直接改写 `P133` 页面项，避免把当前页误标记成“有未保存修改”并触发浏览器离站确认。
- 切换成功并跳转前会调用 `apex.page.cancelWarnOnUnsavedChanges()`，避免仅因切换 `P0_SYSTEM_SWITCH` 就触发浏览器“离开此网站”提示。

## 相关对象
- 页面项：`P0_SYSTEM_SWITCH`
- On-demand process: `SET_CURRENT_SYSTEM`
- Application process: `GET_SYSTEM_OPTIONS`
