# 2026-06-17 清理 f299 无用页面

## 背景

- f299 当前存在一批无侧边导航入口、且不属于弹窗的页面。
- 其中一部分仍被业务页面跳转使用，另一部分更像测试页、备用页或历史残留页。
- 本次目标是只清理明确无用的页面与其导航残留引用，避免误删仍在使用的业务流程页。

## 目标

- 删除确认无用的页面导出文件。
- 同步删除这些页面在面包屑或其他导航资产中的残留引用。
- 不扩展到仍被业务跳转使用的页面。
