## 背景

- 需求范围限定在 APEX 应用层，目标页为 `P156 权限设置`。
- 现状中“添加协作者”仍为 `prompt` 临时实现，不符合文件库权限配置交互要求。

## 本次目标

1. 点击“添加协作者”后切换到独立的选择界面，而不是浏览器弹窗。
2. 选择界面包含“部门”“人员”两个标签。
3. 部门标签展示部门树，可选择部门加入协作者。
4. 人员标签展示人员列表，支持搜索和多选加入协作者。
5. 两个标签页顶部都展示本次已选内容摘要，格式为“已选中***、***”。
6. 加入协作者后按当前权限标签归入 `可管理 / 可查看和下载 / 仅可查看`。

## 影响范围

- 页面：`P156`
- 数据对象：
  - `STS_SCOPE`
  - `STS_FILE`
  - `BASIC_JA_DING_DEPT`
  - `BASIC_USER`
  - `BASIC_JA_DING_USER`

## 实施说明

- 保留现有保存、恢复继承、分享范围能力。
- 新增页内选择态和用户搜索 Ajax。
- 协作者前端选择 key 统一使用 `type + id`，避免部门与人员 ID 冲突。

## 验证目标

1. `P156` 可正常打开，无原始 HTML 字符串展示。
2. 点击“添加协作者”可切换到选择界面。
3. 可在部门/人员标签间切换，并看到已选摘要。
4. 人员列表支持搜索。
5. 选中结果确认后正确回填到协作者列表。
6. 页面可正常保存并关闭。
