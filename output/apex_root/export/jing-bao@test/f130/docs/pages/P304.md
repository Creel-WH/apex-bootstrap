# P304 事件原因关联

## Purpose
- 维护 `原因分类` 与 `事件现象` 的关联关系。
- 支持交互式网格批量新增、编辑、保存。
- 支持模板下载与批量导入。

## Source
- Lanhu screenshot requirement dated `2026-06-08`
- Reference page: `P141`

## Main Region
- Region type: `Interactive Grid`
- Query source: `TENANT_EVNET_PHENOMENON_CAUSE`
- Tenant filter: `TENANT_ID = :USERTENANT`
- Department filter: `BASE_DEPT_ID = :BASE_DEPT_ID`

## Columns
- `原因分类`
  - Column: `CAUSE_NAME`
  - Editable
  - Required
  - Max length: 20
- `事件现象名称`
  - Column: `PHENOMENON_CODE`
  - Popup LOV sourced from `TENANT_EVENT_PHENOMENON`
  - Supports search
  - Required
- `事件现象code`
  - Column: `PHENOMENON_CODE_DISPLAY`
  - Read-only display
  - Auto-filled from the selected `事件现象名称`
- `备注`
  - Column: `REMARK`
  - Optional
  - Max length: 20

## Buttons
- `保存`
  - Uses page-level PL/SQL save logic based on `APEX$ROW_STATUS`
  - New rows write `BASE_DEPT_ID` directly from current session `:BASE_DEPT_ID`
- `模板下载`
  - Reads template config from `APEX_UPLOAD_FILE_CONFIG`
  - Uses `FILE_ID = 1042`
- `批量导入`
  - Toggles upload/preview framework

## Batch Import
- Upload type: `.xlsx`
- Preview columns:
  - `原因分类`
  - `事件现象名称`
  - `备注`
- Current import behavior:
  - Resolves phenomenon name to `TENANT_EVENT_PHENOMENON.CODE`
  - Merges rows into `TENANT_EVNET_PHENOMENON_CAUSE`
  - Updates remark for existing relation rows
  - If a phenomenon name cannot be matched, the import rolls back and reports the exact Excel row number

## Related DB Objects
- `db/tables/tenant_evnet_phenomenon_cause.sql`
- `db/data/seed_event_cause_asso_menu.sql`
- `APEX_UPLOAD_FILE_CONFIG`

## Notes
- Left menu entry is seeded through `AUTH_MENU` data, copied from the same parent context as `P141`.
- New rows default `BASE_DEPT_ID` from the application item `BASE_DEPT_ID` so IG inserts keep the current department context.
- Template download reads file name and file URL from `APEX_UPLOAD_FILE_CONFIG.FILE_ID = 1042`.
