# f138 P202/P204 导入器异常修复
## 基本信息
- 日期: `2026-06-05`
- 环境: `sales-tools@test`
- 应用: `f138`
- 范围: `P202`、`P204`

## 需求
- 修复 `P202/P204` 页面在 APEX importer / APEX Builder 中导入时报错：
  - `ORA-06502: PL/SQL: 数字或值错误: 字符串缓冲区太小`

## 根因
- `P202/P204` 的 `NATIVE_EXECUTE_PLSQL_CODE` 动态动作使用 `p_attribute_01` 保存 PL/SQL 文本。
- 其中 4 段动态动作代码长度超过 `4000`：
  - `P202` 两段分别约 `4287`、`4112`
  - `P204` 两段分别约 `4744`、`4894`
- APEX importer 在写入动态动作属性时触发缓冲区上限，导致页面导入失败。

## 实现
- 仅压缩 `P202/P204` 超长动态动作代码，不改业务分支。
- 合并 `JA_SYSTEM_DICT` 的 3 次查询为 1 次聚合查询。
- 删除未使用变量、注释和冗余空白。
- 将 4 段动态动作长度压缩到 `4000` 以下：
  - `P202`: `3898`、`3798`
  - `P204`: `2691`、`3349`

## 变更文件
- `export/sales-tools@test/f138/apex/f138/application/pages/page_00202.sql`
- `export/sales-tools@test/f138/apex/f138/application/pages/page_00204.sql`
