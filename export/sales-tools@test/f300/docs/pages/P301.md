# P301 维护分平台

## 页面用途
P301 是 APP 300 中用于创建和编辑分平台的共用弹窗页。

## 主要功能

- 录入或修改平台名称
- 选择一个或多个业务管理员
- 编辑模式下回填现有平台名称和业务管理员
- 保存成功后关闭弹窗并返回 `P300`

## 页面实现

- 页面模式为 APEX `Modal Dialog`
- 通过 `P301_SYSTEM_ID` 区分创建模式和编辑模式
- 业务管理员使用原生 Popup LOV，多选值以 `:` 分隔
- Popup LOV 结果区使用页面级样式限制高度并独立滚动；已选管理员标签区不限制高度，避免输入框内部出现滚动条
- 编辑模式只加载当前管理员 ID，由原生 Popup LOV 根据值回显选中标签，页面不再维护额外的显示文本隐藏项
- 取消按钮使用原生 Dialog Cancel
- 保存成功后使用原生 Close Dialog 关闭弹窗

## 数据写入

- 主数据表：`STS_SYSTEM`
- 管理授权表：`STS_SCOPE`
  - `REFERENCE_TYPE='SYSTEM'`
  - `PERMISSIONS_TYPE='MANAGE'`
  - `RANGE_TYPE='USER'`

## 保存规则

- 创建模式：新增 `STS_SYSTEM` 并写入所选管理员授权
- 编辑模式：更新平台名称，并重建该平台当前的管理员授权集合
