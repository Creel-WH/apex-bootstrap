# P300 分平台管理后台

## 页面用途
P300 用于查看和维护分平台列表，是 APP 300 当前唯一主业务页。

## 主要功能

- 查看分平台列表：平台编号、平台名称、业务管理员、创建时间
- 关键字搜索：支持按平台编号、平台名称、业务管理员过滤
- 创建分平台：以弹窗形式打开 `P301`
- 编辑分平台：以弹窗形式打开 `P301`
- 删除分平台：逻辑删除并清理对应管理员授权
- 进入分平台：切换当前 `SYSTEM_ID` 后跳转到 APP 138 的文件管理平台入口 `P133`，并将目标应用 `SYSTEM_ID` 设置为所选分平台

## 页面实现

- 主列表使用 APEX 原生 SQL Report 承载
- 页面级隐藏 APEX 侧边栏，保持单页后台体验
- 顶部保留关键字搜索框和创建按钮
- 列表操作区包含 `进入 / 编辑 / 删除`
- `进入` 先调用 `SET_CURRENT_SYSTEM`，成功后跳转到 APP 138 的公共登录页 `P9999`，使用 `session=0` 和 `PUBLIC_BOOKMARK` checksum 携带 `P300_HANDOFF` 请求、当前登录人工号和当前行 `SYSTEM_ID`；`P9999` 服务端完成 APP 138 登录态建立后再进入 `P133`
- `创建` 与 `编辑` 都通过 `apex.navigation.dialog` 打开 `P301`
- 弹窗打开高度固定为 560，避免 P301 多选业务管理员时父弹窗随内容高度变化而抖动
- `P301` 弹窗关闭后，P300 自动刷新报表区域

## 数据读写

- 主数据表：`STS_SYSTEM`
- 管理授权表：`STS_SCOPE`
  - `REFERENCE_TYPE='SYSTEM'`
  - `PERMISSIONS_TYPE='MANAGE'`
  - `RANGE_TYPE='USER'`

## 备注

- 当前“系统”业务语义即“子平台 / 分平台”
- 该页面已从原 APP 138 拆分到独立应用 `f300`
