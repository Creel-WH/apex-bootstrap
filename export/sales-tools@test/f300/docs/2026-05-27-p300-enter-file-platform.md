# P300 Enter File Platform

## Request
- Original Request: 点击进入按钮要求跳转至p138的文件管理平台，并将子平台改为当前跳转的平台
- AI Summary: 调整 APP 300 分平台列表的“进入”动作，进入所选子平台时跳转到 APP 138 文件管理平台，并让目标应用的当前子平台上下文等于所选平台。
- Business Goal: 分平台管理后台作为入口页，用户点击某个分平台的“进入”后，应直接进入文件管理平台并看到该分平台对应的数据上下文。
- Acceptance Criteria:
  1. P300 点击任一分平台的“进入”后跳转到 APP 138 文件管理平台入口。
  2. 跳转后的 APP 138 当前 `SYSTEM_ID` 为所点击分平台的 `SYSTEM_ID`。
  3. 不改变 P300 的新增、编辑、删除流程。
  4. APEX export 与页面文档同步更新。

## Analysis
- `P300` 当前“进入”按钮调用 `SET_CURRENT_SYSTEM` 后重定向回 `f?p=&APP_ID.:300:&APP_SESSION.`。
- APP 138 已有应用项 `SYSTEM_ID`，页面查询按 `:SYSTEM_ID` 过滤。
- APP 138 的文件管理功能基线指向 `f?p=138:133`。
- 该变更可先限定在 APP 300 P300：由入口页构造跨应用跳转 URL，并设置目标 APP 138 的 `SYSTEM_ID`。
