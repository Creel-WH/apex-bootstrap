# P130 文件库

## 页面定位
- 页面: `P130`
- 用途: 展示顶层文件库列表，并提供进入 `P133` 详情页的入口。

## 当前行为
- 列表数据来自 `STS_FILE`，仅展示 `FILE_LEVEL = 1` 且未删除的顶层文件库。
- 文件库名称点击后跳转到 `P133`，进入对应文件库的明细列表。
- 列表默认按 `NVL(SORT_NUM, 999999), FILE_ID` 展示。

## 2026-06-08 顶层文件库拖拽排序
- 新增 `排序` 列，作为顶层文件库列表的拖拽入口。
- 仅非 `VIEW_REPORT` 角色可拖拽排序；查看角色仍保持只读。
- 前端在 `content` IG 上使用原生拖拽调整当前列表顺序。
- 拖拽后通过页面 on-demand 进程 `SAVE_FILE_LIBRARY_ORDER` 持久化到 `STS_FILE.SORT_NUM`。
- 保存成功后刷新 `P130` 当前列表，展示最新顺序。
- 本次排序仅调整 `SORT_NUM`，不更新无关审计字段。
