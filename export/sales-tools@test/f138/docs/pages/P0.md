# P0 Global Page

## Purpose
P0 provides global behavior for the 文件管理平台 application.

## System Switcher
- The global page injects a top-bar business-system switcher after page load.
- System options are loaded from the application on-demand process `GET_SYSTEM_OPTIONS`.
- Switching system calls the application on-demand process `SET_CURRENT_SYSTEM`.
- Successful switching updates the APEX session state item `SYSTEM_ID` and reloads the current page.
- `USER_TENANT` remains unchanged and continues to drive existing permission/menu display logic.
- Only enabled and not deleted rows from `STS_SYSTEM` are shown.

## Related Database Objects
- `STS_SYSTEM`
