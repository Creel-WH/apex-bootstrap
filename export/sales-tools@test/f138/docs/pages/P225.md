# P225 切换角色

## 2026-06-05 文件库管理员切换恢复
- 角色切换 LOV 不再只读取 `STS_USER_ROLE` 里的既有角色记录。
- 当当前用户拥有以下任一 `MANAGE` 权限时，会动态补出 `FOLDER_REPORT`：
  - 文件库 `FOLDER_LIB`
  - 文件夹 `FOLDER`
  - 文件 `FILE`
- 支持用户直授和部门授权两种范围。
- 若用户已存在文件库管理员角色记录，则不重复补出虚拟角色项。
- 目的：恢复“授予可管理权限后，右上角可切换到文件库管理员”的历史能力。
- 当前已导入 `sales-tools@test/f138`。
