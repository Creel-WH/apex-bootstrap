# P133 文件库详情

## 页面定位

P133 是文件管理平台测试环境应用 f138 的文件库详情页，用于展示当前文件夹下的文件与子文件夹，并承载新建文件夹、上传文件、删除、归档、迁移、预览、重命名、权限设置等文件管理入口。

## 结构与交互

- 运行时不再展示左侧 FancyTree 树组件。
- 主内容区 `content` 是网盘式单层 Interactive Grid，每次只展示 `P133_PARENT_FOLDER_ID` 对应目录下的同级内容。
- 顶部路径条 `#p133_pathbar` 展示当前目录层级，包含返回上级、可点击面包屑和刷新当前目录。
- 面包屑由 `P133_BREADCRUMB_JSON` 渲染，每一级包含目录 `FILE_ID` 和 `FILE_NAME`。
- 点击任一级 `.p133-crumb` 会设置 `P133_PARENT_FOLDER_ID` 为该级目录 id，并复用现有动态动作刷新当前列表。
- 点击名称列中文件夹进入下级目录，点击文件进入预览页。
- 删除、归档、迁移等批量操作继续基于 IG 选中行写入 `P133_FILE_IDS` / `P133_FILE_TYPES` 后执行。

## 关键页面项

- `P133_ROOT_FOLDER_ID`：当前文件库根目录。
- `P133_PARENT_FOLDER_ID`：当前列表所在目录，也是列表查询和面包屑跳转的核心条件。
- `P133_UP_FOLDER_ID`：当前目录的上级目录，用于路径条返回上级。
- `P133_BREADCRUMB_JSON`：当前目录从根到当前位置的面包屑 JSON。
- `P133_FILE_ID`：当前点击或选中的文件/文件夹。
- `P133_FILE_TYPE`：当前点击对象类型，`FOLDER` 进入目录，`FILE` 进入预览。
- `P133_FILE_IDS` / `P133_FILE_TYPES`：IG 多选后的批量操作上下文。

## 数据来源

主列表区域 `content` 查询 `STS_FILE`，条件为：

- `TENANT_ID = :USER_TENANT`
- `DEL_FLAG = 0`
- `PARENT_FOLDER_ID = :P133_PARENT_FOLDER_ID`
- 复用原有角色、文件范围和用户/部门权限过滤条件。

面包屑数据只读查询 `STS_FILE` 当前目录祖先链，不新增数据库对象。

## 2026-05-18 Update (Permission Render Guard)

- `P133` manager visibility check was aligned to a unified `CASE + EXISTS` pattern.
- `BUSINESS_ADMIN` now checks `STS_SCOPE` by `REFERENCE_TYPE='SYSTEM'` + `PERMISSIONS_TYPE='MANAGE'` under current `SYSTEM_ID`.
- Folder/file manage visibility remains controlled by `STS_SCOPE` (`REFERENCE_TYPE='FILE'`, `PERMISSIONS_TYPE='MANAGE'`) with user/dept matching.
- This change removes previous region-render SQL instability and keeps display behavior deterministic.
