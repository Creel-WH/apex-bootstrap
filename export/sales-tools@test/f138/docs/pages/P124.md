# P124 文件管理

## 2026-06-05 管理按钮权限恢复
- 上传按钮的显示条件不再只依赖 `STS_USER_ROLE`。
- 当当前角色为文件库管理视角时，页面会直接按 `STS_SCOPE` 判断当前用户是否拥有当前文件库范围内的 `MANAGE` 权限。
- 支持两类授权范围：
  - `RANGE_TYPE = 'USER'`
  - `RANGE_TYPE = 'DEPT'`，通过 `BASIC_JA_DING_DEPT_USER` 展开成员
- 目的：用户通过文件库/文件夹/文件的管理权限切换到文件库管理员视角后，页面内管理按钮仍能正常显示。
