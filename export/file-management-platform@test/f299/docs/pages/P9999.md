# P9999 登录页

## 用途

- 应用登录入口页。
- 保留原有账号密码登录、钉钉扫码登录和免登页面流程。

## 当前登录口径

- APEX 认证方案 `STS_LOGIN` 已切换为：
  - 认证函数：`FMP_APEX_LOGIN`
  - 登录后处理：`FMP_LOGIN_SUCCESS`
- 账号来源改为 `BASIC_JA_DING_USER`。
- 所有未离职用户默认使用“工号=密码”登录。
- `JA016181` 的登录密码固定为 `lwh123..`。

## 登录后会话初始化

- 登录成功后会从 `BASIC_JA_DING_USER` 获取人员信息。
- 若 `STS_USER` 中不存在对应工号，则自动补齐最小账号记录，用于兼容现有页面的会话与审计字段。
- 若用户已有 `STS_USER_ROLE` 角色，则继续沿用最高级别角色。
- 若用户无角色，则默认按 `VIEW_REPORT` 口径初始化只读角色会话值。
## 2026-06-18 补充

- 账号来源补充为 `BASIC_USER` 与 `BASIC_JA_DING_USER` 的并集。
- 新登录用户登录成功后会自动创建或同步 `FMP_USER`。
- 默认密码改为 `Aa135246..`，`JA016181` 的密码固定为 `lwh123..`。
## 2026-06-29 补充

- `FMP_LOGIN_SUCCESS` 不再只依赖 `P9999_USERNAME`，而是优先使用认证后的 APEX 用户名，再回退到页面项和登录用户名 cookie。
- 登录后来源数据会优先选择当前租户 `tenant_id = 3` 的有效 `BASIC_USER` 记录，再与最新有效 `BASIC_JA_DING_USER` 记录合并，避免同工号多来源时取数不稳定。
