# P133 文件库

## Purpose
- 作为 `f299` 文件库统一入口页，替代原 `P130` 的首页入口职责。
- 根层展示原文件库一级目录，并统一按文件夹方式浏览。
- 在同一页内支持列表视图和网格视图切换。

## Current Behavior
- 页头样式参考 `D:/ja-projects/html/platform-list.html`，标题位于顶部，根层仅展示允许操作的主按钮。
- 根层只显示“新建文件夹”，不显示“上传文件”。
- 非根层在有管理权限时显示“上传文件”。
- 选择条目后，顶部操作区按选择数量展示可执行按钮：
  - 单选时显示分享、重命名、移动、权限设置、删除。
  - 多选时显示移动、删除。
- 面包屑第一项固定为“文件库”，可返回根层。
- 列表视图基于 APEX Interactive Grid 区域 `content`。
- 网格视图基于前端渲染的 `#p133_grid_view` 卡片列表。

## Notes
- 根层查询使用 `P133_PARENT_FOLDER_ID is null` 匹配顶层目录，避免出现首页无数据。
- 视图切换时保留当前选中状态，并同步回 `P133_FILE_IDS`、`P133_FILE_TYPES`、`P133_FILE_ID`、`P133_FILE_TYPE`。
- 页面已移除归档状态展示和回收站入口。
