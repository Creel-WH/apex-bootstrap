# P133 文件库

## Purpose

- 作为 `f299` 文件库统一入口页，支持目录浏览、文件打开和批量操作。
- 在同一页面内提供列表视图与卡片视图切换。

## Current Behavior

- 顶部保留“新建文件夹”“上传文件”等原有入口；根层仅展示允许执行的主操作。
- 列表内容按当前会话 `SYSTEM_ID` 过滤，只显示当前子平台下的文件和文件夹。
- 列表视图基于 APEX Interactive Grid 区域 `content`，卡片视图基于前端渲染的 `#p133_grid_view`。
- 排序菜单支持：
  - `文件名`
  - `更新时间从近到远`
  - `更新时间从远到近`
  - `创建时间从近到远`
  - `创建时间从远到近`
  - `默认`
- `SORT_NUM` 为列表视图固定字段定义：
  - 非手动排序时隐藏；
  - 默认排序时显示；
  - 不再展示原“大小”列。
- 当处于列表视图、排序模式为 `默认` 且当前文件夹具备管理权限时：
  - `SORT_NUM` 列作为拖拽句柄；
  - 可拖拽调整当前文件夹下所有同级文件 / 文件夹顺序；
  - 不再逐个判断每个文件的管理权限。
- 拖拽保存通过页面 on-demand 过程 `SAVE_FILE_LIBRARY_ORDER` 持久化到 `FMP_FILE.SORT_NUM`。
- 拖拽排序保存仅更新 `SORT_NUM`，不更新“更新人 / 更新时间”字段。
- 选中条目后的按钮权限规则：
  - 有管理权限时，维持原有分享、重命名、移动、权限设置、删除能力；
  - 无管理权限但单选文件 / 文件夹时，仍可点击“分享”和“权限查看”；
  - 多选且存在无管理权限对象时，仅保留原只读选择状态，不开放改动类操作。

## Notes

- 手动拖拽仅作用于当前文件夹 siblings，不影响其他目录。
- 若 IG 因 frozen pane 将排序列渲染在前侧 pane，拖拽仍从当前可见排序列起拖，但实际顺序计算仍只认同一份 canonical siblings 列表。
- 拖拽绑定会在 IG 刷新、翻页后重新初始化。
- 文件或文件夹移动到其他目录后，源目录和目标目录都会分别重排 `SORT_NUM`，保证每个文件夹下的序号独立连续。
- `P156` 权限页会根据当前对象的 `manage` 权限自动切换为可编辑或只读查看模式。
