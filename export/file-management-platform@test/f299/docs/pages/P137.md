# P137 文件预览

## Purpose

- 作为 `f299` 的文件预览页，负责打开单个文件的在线预览。
- 页面当前只处理预览展示与来源感知导航，不承载文件库目录浏览能力。

## Current Behavior

- 页面根据 `P137_FILE_ID` 读取单个文件信息，并尝试将 `FILE_URL` 解析为可预览地址。
- 页面标题栏右侧提供 3 个原生 APEX 图标按钮：收藏、文档详情、文档下载。
- 收藏按钮会基于 `FMP_FAVORITE_FILE` 实时切换空心/实心星标。
- 文档详情使用右侧抽屉展示文件名、类型、大小、上传人、上传时间、最新修改、位置、文件 ID、文件链接。
- 文档下载通过页面内隐藏下载通道触发，不离开当前预览页。
- 当来源是 `P133` 时：
  - 返回上级会回到进入前的 `P133` 目录层级。
  - 隐藏原生面包屑区域与底部完整路径展示，只保留页面内的自定义补充面包屑。
- 当来源是 `P1` 首页模块时：
  - 返回上级会回到 `P1`。
  - 隐藏原生面包屑区域与底部完整路径展示，只保留页面内的自定义补充面包屑。
- 当没有显式来源参数时：
  - 页面会回退到当前文件所属的父文件夹层级，并返回 `P133`。
