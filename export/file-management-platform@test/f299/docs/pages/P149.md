# P149 回收站

## Purpose

- 作为 `f299` 文件管理平台的回收站入口页，统一展示当前子平台下已删除且当前用户可管理的文件/文件夹。
- 提供恢复、彻底删除、清空回收站能力。

## Current Behavior

- 页面为标准页面，不再使用旧版模态回收站实现。
- 左侧导航底部提供“回收站”入口，当前页高亮。
- 列表主体使用 `Interactive Grid` region `content`。
- 列表字段包含：
  - 文件名
  - 大小
  - 删除人
  - 剩余天数
  - 删除时间
  - 行内操作
- 顶部左侧保留 `清空回收站` 按钮。
- 顶部右侧保留 `刷新` 按钮，点击后仅刷新列表区并提示“回收站已刷新”。
- 选择 IG 行后显示批量操作条：
  - `还原`
  - `彻底删除`

## Data Scope

- 数据来源：`FMP_FILE` + `FMP_P133_FILE_LIBRARY_V`
- 过滤条件：
  - `tenant_id = :USER_TENANT`
  - `system_id = 当前 SYSTEM_ID`
  - `del_flag = -1`
- 权限口径：
  - `SYSTEM_ADMIN / SUPER_ADMIN` 全量可见
  - 其他用户仅可见 `fmp_is_file_manager(...) > 0` 的已删除对象

## Interaction Notes

- 剩余天数按 `120 - trunc(sysdate - nvl(del_date, update_date))` 计算，7 天及以内显示红色提醒。
- 单行操作和批量操作都通过页面 on-demand process 执行。
- 恢复时会先检查选中对象是否仍依赖未恢复的父文件夹；若存在阻塞，会先提示恢复父级。
- 恢复会连同选中对象的后代节点一起恢复。
- 彻底删除会删除选中对象及其后代节点，并同步清理 `FMP_SCOPE` 中对应 `FILE` 权限记录。
- 清空回收站按当前页面可见范围执行，不扩展到其他子平台。
- 清空回收站前会先弹出二次确认，确认后才调用彻底删除流程。
