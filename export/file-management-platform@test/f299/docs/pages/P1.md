# P1 首页

## Purpose

- 作为 `f299` 的首页内容页，集中展示当前子平台下的文件动态与快捷入口。
- 当前阶段只覆盖 `P1` 主体及配套弹窗，不处理 `P0` 顶部和首页顶部搜索。

## Current Behavior

- 页面主体已切换为 APEX 原生首页骨架：
  - 已移除 `P1` 内自带页面标题与首页介绍块，不影响 `P0` 顶部
  - 主体分栏使用 `Display Selector / Tabs Container`
  - 当前包含 `最近访问`、`我的关注`、`与我分享`、`我分享的` 四个页签
- `最近访问`
  - 当前使用只读 APEX `Interactive Grid` 展示文件列表
  - 文件名单元格复用 `P133` 的文件类型图标展示方式
  - 列表字段为 `文件`、`大小`、`类型`、`更新人`、`最近打开时间`
  - 数据取自 `FMP_OPERATION_LOG` 最近操作记录，并关联 `FMP_FILE` / `BASIC_USER`
  - 仅展示文件条目，过滤 `FMP_FILE.FILE_TYPE = 'FOLDER'` 的文件夹条目
- `我的关注`
  - 已接入 `FMP_FAVORITE_GROUP` 与 `FMP_FAVORITE_FILE`
  - 分组胶囊使用原生 `Cards`，关注文件列表使用只读 APEX `Interactive Grid`
  - 分组区、维护按钮区和文件列表均已收敛为 headerless/noUI 风格，减少 APEX 默认多层外框
  - 关注文件列表字段为 `文件`、`大小`、`类型`、`更新人`、`关注时间`、`操作`
  - 已支持：
    - 分组切换
    - 新增分组弹窗入口 `P157`
    - 编辑分组弹窗入口 `P157`
    - 删除分组
    - 取消关注
    - 文件名点击进入文件预览页
- `与我分享`
  - 已接入 `FMP_SCOPE` 文件级分享数据
  - 当前使用只读 APEX `Interactive Grid` 展示分享来源、权限类型与最近时间
  - 列表区域已改为 headerless/noUI 文件表格卡片，列标题为 `文件`、`来源`、`分享时间`、`操作`
  - 已支持：
    - 文件名点击进入文件预览页
    - 通过 `P156` 查看权限详情
- `我分享的`
  - 已接入当前用户发起的 `FMP_SCOPE` 文件级分享数据
  - 当前使用只读 APEX `Interactive Grid` 展示分享范围摘要与最近调整时间
  - 列表区域已改为 headerless/noUI 文件表格卡片，列标题为 `文件`、`范围`、`更新时间`、`操作`
  - 已支持：
    - 文件名点击进入文件预览页
    - 通过 `P156` 进入分享编辑/查看入口

## 2026-07-01 Update

- The four file-list modules on `P1` now use read-only APEX `Interactive Grid` regions, aligned with the `P133` list-view interaction model.
- File-name cells reuse the `P133` icon semantics through `ICON_CLASS`, with the file name rendered as an HTML expression link.
- `我的关注`, `与我分享`, and `我分享的` keep their existing lightweight row actions inside the IG operation column.
- `最近访问` was flattened to a single visual file-list card: the `P1` page title/intro regions were removed, the tab content wrapper is headerless, and the recent list now shows file-only operation-log rows with `文件 / 大小 / 类型 / 更新人 / 最近打开时间`.
- The remaining three modules were also visually flattened: their tab-content wrappers and file-list regions now use headerless/noUI region chrome, the favorite group pills follow the prototype gray/blue capsule style, and `我的关注` now uses the same file-table column rhythm as the home prototype.
