# P1 首页

## Purpose

- 作为 `f299` 的首页内容页，集中展示当前子平台下的文件动态与快捷入口。
- 当前阶段只覆盖 `P1` 主体及配套弹窗，不处理 `P0` 顶部和首页顶部搜索。

## Current Behavior

- 页面主体已切换为 APEX 原生首页骨架：
  - 已移除 `P1` 内自带页面标题与首页介绍块，不影响 `P0` 顶部
  - 主体分栏使用 `Display Selector / Tabs Container`
  - 当前显示 `最近访问`、`我的关注` 两个页签；`与我分享`、`我分享的` 暂时通过显示条件隐藏，保留区域与 SQL 便于后续恢复
- `最近访问`
  - 当前使用只读 APEX `Interactive Grid` 展示文件列表
  - 文件名单元格复用 `P133` 的文件类型图标展示方式
  - 列表字段为 `文件`、`大小`、`类型`、`更新人`、`最近打开时间`
  - 数据取自 `FMP_OPERATION_LOG` 最近操作记录，并关联 `FMP_FILE` / `BASIC_USER`
  - 仅展示文件条目，过滤 `FMP_FILE.FILE_TYPE = 'FOLDER'` 的文件夹条目
  - 文件预览链接会携带 `P137_SOURCE_PAGE=1` 与模块标识，供 `P137` 返回首页时识别来源
- `我的关注`
  - 已接入 `FMP_FAVORITE_GROUP` 与 `FMP_FAVORITE_FILE`
  - 分组栏使用 `Static Content` 承载 Universal Theme `t-Tabs` 结构，并通过 `P1_FAVORITE_GROUP_TABS_DATA` Ajax Callback 动态查询 `FMP_FAVORITE_GROUP`；关注文件列表使用只读 APEX `Interactive Grid`
  - 分组栏与文件列表为上下结构；左侧动态输出 `全部 + 用户分组` tabs，右侧使用原生 Button 提供 `新增分组` 入口
  - 不再使用 Cards 分组卡片或负 margin 拼接，减少 APEX 默认多层外框
  - 关注文件列表字段为 `文件`、`大小`、`类型`、`更新人`、`最近打开时间`
  - `最近打开时间` 取当前用户对该文件的最新 `FMP_OPERATION_LOG.creation_date`，无操作记录时回退 `FMP_FAVORITE_FILE.favorite_date`
  - 仅展示文件条目，过滤 `FMP_FILE.FILE_TYPE = 'FOLDER'` 的文件夹条目
  - 已支持：
    - 分组切换
    - 新增分组弹窗入口 `P157`，通过 P1 Ajax Callback 生成带 checksum 的安全弹窗 URL
    - 编辑分组弹窗入口 `P157`
    - `P157` 新增/编辑保存关闭后，通过 `apexafterclosedialog` 刷新关注分组与关注文件区域
    - 文件名点击进入文件预览页
    - 文件预览链接会携带 `P137_SOURCE_PAGE=1` 与模块标识，供 `P137` 返回首页时识别来源
- `与我分享`
  - 已接入 `FMP_SCOPE` 文件级分享数据
  - 当前使用只读 APEX `Interactive Grid` 展示分享来源、权限类型与最近时间
  - 仅展示文件条目，过滤 `FMP_FILE.FILE_TYPE = 'FOLDER'` 的文件夹条目
  - 列表区域已改为 headerless/noUI 文件表格卡片，列标题为 `文件`、`来源`、`分享时间`、`操作`
  - 已支持：
    - 文件名点击进入文件预览页
    - 通过 `P156` 查看权限详情
  - 文件预览链接会携带 `P137_SOURCE_PAGE=1` 与模块标识，供 `P137` 返回首页时识别来源
- `我分享的`
  - 已接入当前用户发起的 `FMP_SCOPE` 文件级分享数据
  - 当前使用只读 APEX `Interactive Grid` 展示分享范围摘要与最近调整时间
  - 仅展示文件条目，过滤 `FMP_FILE.FILE_TYPE = 'FOLDER'` 的文件夹条目
  - 列表区域已改为 headerless/noUI 文件表格卡片，列标题为 `文件`、`范围`、`更新时间`、`操作`
  - 已支持：
    - 文件名点击进入文件预览页
    - 通过 `P156` 进入分享编辑/查看入口
  - 文件预览链接会携带 `P137_SOURCE_PAGE=1` 与模块标识，供 `P137` 返回首页时识别来源

## 2026-07-01 Update

- The four file-list modules on `P1` now use read-only APEX `Interactive Grid` regions, aligned with the `P133` list-view interaction model.
- File-name cells reuse the `P133` icon semantics through `ICON_CLASS`, with the file name rendered as an HTML expression link.
- `我的关注`, `与我分享`, and `我分享的` keep their existing lightweight row actions inside the IG operation column.
- `最近访问` was flattened to a single visual file-list card: the `P1` page title/intro regions were removed, the tab content wrapper is headerless, and the recent list now shows file-only operation-log rows with `文件 / 大小 / 类型 / 更新人 / 最近打开时间`.
- The remaining three modules were also visually flattened: their tab-content wrappers and file-list regions now use headerless/noUI region chrome, the favorite group pills follow the prototype gray/blue capsule style, and `我的关注` now uses the same file-table column rhythm as the home prototype.

## 2026-07-03 Update

- `我的关注` was refactored to the prototype-like vertical structure: native Cards group pills on top and a read-only Interactive Grid file list below.
- The group selector now uses native `Cards` with a tabs-like Universal Theme visual treatment, so runtime favorite groups remain SQL-driven; the add-group entry is a native Button aligned on the right and reuses `P157`.
- The favorite file IG now shows only `文件 / 大小 / 类型 / 更新人 / 最近打开时间`, hides the old operation column from the default report, filters out folders, and derives recent open time from `FMP_OPERATION_LOG` with favorite time as fallback.
- The add/edit favorite-group dialog URL is generated by the `P1_FAVORITE_GROUP_DIALOG_URL` Ajax Callback so protected modal page `P157` receives a valid checksum.
- `P1` no longer overrides the `P157` modal title in JavaScript; `P157` now renders its own `关注分组` title and uses native APEX Form submit buttons for create/update.

## 2026-07-03 Favorite Tabs Update

- `我的关注` group selector no longer uses Cards or Classic Report; region `p1_favorite_groups_rpt` is now `Static Content` and renders Universal Theme `t-Tabs` markup from Ajax data.
- Closing `P157` after `CREATE/SAVE` triggers the existing `apexafterclosedialog` listener on `P1`, refreshing `p1_favorite_groups_rpt` and `p1_favorite_files_rpt`.
- The main display selector spacing was tightened so the top module tabs sit closer to the active tab content while keeping the divider line.

## 2026-07-03 User Key Update

- Favorite groups and favorite files now use `MPF_USER_ID` as the owner key.
- `MPF_USER_ID` is aligned to `BASIC_USER.USER_ID` after login, while session `USER_ID` remains `FMP_USER.USER_ID`.

## 2026-07-06 Recent Access Update

- `最近访问` still reads recent file rows from `FMP_OPERATION_LOG` joined to `FMP_FILE`.
- `P137` now writes a `VIEW / FILE_PREVIEW` operation log when a real file preview is opened.
- The recent-access log filter now matches both `MPF_USER_ID` and `DIAN_USER_ID`, so new preview logs and older operation logs can both appear.
- Folder rows remain excluded by `upper(nvl(FMP_FILE.FILE_TYPE, 'FILE')) <> 'FOLDER'`.
