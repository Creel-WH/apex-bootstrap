# P157 关注分组弹窗

## Purpose

- 用于新增或重命名当前用户的关注分组。

## Current Behavior

- 页面为模态弹窗页。
- 页面标题由 `P157` 自身的页面标题 `关注分组` 渲染，`P1` 打开弹窗时不再覆盖 `apex.navigation.dialog` 的 `title`。
- 主体使用 APEX 原生 `Form` 区域，数据源为 `FMP_FAVORITE_GROUP`。
- 通过 `P157_FAVORITE_GROUP_ID` 判断是新增还是编辑：
  - 为空：新增分组
  - 有值：编辑现有分组
- 分组名称输入项为 `P157_GROUP_NAME`。
  - 输入项模板尺寸为 `X Large`。
- 隐藏列 `P157_USER_ID`、`P157_SORT`、`P157_DEL_FLAG` 用于原生表单新增时补齐当前用户、排序和删除标记默认值。
- 保存按钮使用 APEX 表单默认提交逻辑：
  - `CREATE`：`P157_FAVORITE_GROUP_ID` 为空时显示，执行原生 `SQL INSERT action`
  - `SAVE`：`P157_FAVORITE_GROUP_ID` 非空时显示，执行原生 `SQL UPDATE action`
- 页面进程使用 APEX 原生 `Form - Automatic Row Processing (DML)` 与 `Close popup window`。
- `准备表单默认值` 页面进程在原生 DML 前执行，仅补齐 `P157_USER_ID`、`P157_SORT`、`P157_DEL_FLAG` 的会话值，不直接写表。
- 保存规则：
  - 新增场景按当前用户已有最大 `SORT` 顺序追加。
  - 编辑场景更新表单绑定列。
- 编辑保存前会校验目标分组属于当前 `MPF_USER_ID` 且未删除。
- `CREATE/SAVE` 成功后执行 `Close popup window`，父页面 `P1` 通过 `apexafterclosedialog` 刷新关注分组与关注文件区域。
- 取消按钮使用默认 `Cancel Dialog` 动态动作直接关闭弹窗，不改数据。
