# P157 关注分组弹窗

## Purpose

- 用于新增或重命名当前用户的关注分组。

## Current Behavior

- 页面为模态弹窗页。
- 通过 `P157_FAVORITE_GROUP_ID` 判断是新增还是编辑：
  - 为空：新增分组
  - 有值：编辑现有分组
- 分组名称输入项为 `P157_GROUP_NAME`。
- 保存时：
  - 新增场景按当前用户已有最大 `SORT` 顺序追加。
  - 编辑场景仅更新名称与 `UPDATE_DATE`。
- 取消直接关闭弹窗，不改数据。

## Related Data

- `FMP_FAVORITE_GROUP`

## Related Pages

- `P1`：首页中的“我的关注”模块会打开本弹窗
