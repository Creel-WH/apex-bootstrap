# P221 页面管理

## 用途

- 系统设置下的页面管理页。
- 仅子平台管理员可访问。
- 用于按当前子平台配置导航菜单中哪些页面显示、哪些页面隐藏。

## 访问控制

- 访问人通过 `FMP_SCOPE` 判断是否具有当前 `SYSTEM_ID` 的 `MANAGE` 权限。
- 判断逻辑由数据库函数 `FMP_IS_SYSTEM_MANAGER` 承担。

## 页面行为

- 页面树来源于 `FMP_PERMISSION` 中 `PERMISSION_TYPE = 0` 的页面权限数据。
- 勾选结果写入 `FMP_PAGE_CONFIG`。
- 配置维度为 `SYSTEM_ID + TENANT_ID + PAGE_ID`。
- 保存后，主导航菜单和系统设置导航会通过 `FMP_IS_PAGE_MANAGED_VISIBLE` 读取配置并控制显示。
