# P227 管理后台

## 用途

- 管理后台首期页。
- 当前只开放“平台名称修改”。
- “路径修改”暂不实现。
- “统计功能”仅保留空白区域占位。

## 访问控制

- 仅子平台管理员可访问。
- 页面进入前通过 `FMP_IS_SYSTEM_MANAGER` 校验当前 `SYSTEM_ID / DIAN_USER_ID / USER_TENANT`。

## 当前行为

- 页面使用区域显示选择器将“平台信息”和“统计功能”拆分为两个独立区域。
- 页面从当前 `SYSTEM_ID` 对应的 `FMP_SYSTEM.SYSTEM_NAME` 读取当前子平台名称作为默认值。
- 如果当前子平台不可用，则回退显示当前 APEX `APP_NAME`。
- 点击保存后：
  - 直接更新当前 `SYSTEM_ID` 对应的 `FMP_SYSTEM.SYSTEM_NAME`。
- 如果当前子平台在当前租户下存在最高级根文件夹，则会同步更新该根文件夹名称。
- 根文件夹改名后，会同步重算该目录树的 `FILE_LEVEL / FILE_PATH / ROOT_FOLDER_ID`，避免文件库根目录识别与面包屑路径失真。
- 切换子平台后，页面会随当前会话中的 `SYSTEM_ID` 自动显示对应子平台名称。
- 保存后刷新页面时，`P0` 顶部子平台切换模块会同步显示更新后的名称，因为它同样读取 `FMP_SYSTEM`。
- 页面不再显示首期说明提示文案。

## 相关对象

- 页面项：`P227_PLATFORM_NAME`
- 表：`FMP_SYSTEM`
