# P156 权限设置 / 权限查看

## Purpose

- 用于查看或维护文件 / 文件夹的分享范围与协作者权限。

## Current Behavior

- 页面以模态页方式打开。
- 页面打开时会先解析当前用户对当前文件 / 文件夹的 `manage` 权限。
- 顶部标题按当前对象名展示；无管理权限时追加“权限查看”提示。
- 协作者按权限分组展示：
  - `可管理`
  - `可查看和下载`
  - `仅可查看`
- 具备 `manage` 权限时，允许：
  - 添加协作者；
  - 移除协作者；
  - 调整协作者角色；
  - 修改分享范围；
  - 保存权限；
  - 恢复继承。
- 不具备 `manage` 权限时：
  - 分享范围、添加协作者、移除协作者、角色修改、保存、恢复继承全部禁用；
  - 协作者权限下拉不可编辑；
  - 分享范围不可修改；
  - 页面用于查看现有权限信息。
- 当前操作人自己的 `manage` 协作者行不可删除，也不可降级为非管理角色。
- 点击“恢复继承”后，页面会重新加载并展示继承自上级文件夹的协作者权限。
- `file_level<=2` 按业务顶级对象处理：
  - 不显示“已限制权限”提示；
  - 不显示“恢复继承”语义；
  - 协作者来源不展示“继承自上级”；
  - 保存后当前弹窗会立即重新拉取最新权限状态。

## Related Data

- 主体文件：`FMP_FILE`
- 权限范围：`FMP_SCOPE`
- 部门来源：`BASIC_JA_DING_DEPT`
- 人员来源：`BASIC_USER`、`BASIC_JA_DING_USER`
