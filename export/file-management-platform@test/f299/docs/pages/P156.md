# P156 权限设置

## 页面用途

用于配置文件或文件夹的分享范围与协作者权限。

## 当前交互

- 页面以模态页方式打开。
- 顶部支持查看和修改分享范围。
- 协作者按权限分组展示：
  - `可管理`
  - `可查看和下载`
  - `仅可查看`
- 点击“添加协作者”后切换到页内选择界面：
  - `部门` 标签展示部门树并支持多选。
  - `人员` 标签展示人员列表，支持搜索与多选。
  - 两个标签页均展示“已选中...”摘要。
- 确认后按当前权限标签把选中的部门/人员加入协作者列表。
- 支持保存权限、恢复继承。

## 相关数据

- 主体文件：`FMP_FILE`
- 权限范围：`FMP_SCOPE`
- 部门来源：`BASIC_JA_DING_DEPT`
- 人员来源：`BASIC_USER`、`BASIC_JA_DING_USER`
