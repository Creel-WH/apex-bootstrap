# P156 权限设置 / 权限查看

## Purpose

- 查看或维护文件 / 文件夹的分享范围与协助者权限。

## Current Behavior

- 页面以模态页方式打开。
- 协助者分类页签在选中或聚焦时保留蓝色文字和下划线，不再显示额外的蓝色外框阴影。
- 页面打开时先解析当前用户对当前文件 / 文件夹是否具备 `manage` 权限。
- 标题按当前对象名称展示；无管理权限时追加“权限查看”提示。
- 协助者按权限分组展示：
  - `可管理`
  - `可查看和下载`
  - `仅可查看`
- 具备 `manage` 权限时允许：
  - 添加协助者
  - 移除协助者
  - 调整协助者角色
  - 修改分享范围
  - 保存权限
  - 恢复继承
- 不具备 `manage` 权限时：
  - 分享范围、添加协助者、移除协助者、角色修改、保存、恢复继承全部禁用
  - 协助者权限下拉不可编辑
  - 页面仅用于查看当前权限信息
- 当前操作人自己的 `manage` 协助者行不可删除，也不可降级为非管理角色。
- `file_level<=2` 按业务顶级对象处理：
  - 不显示“已限制权限”提示
  - 不提供“恢复继承”语义
  - 协助者来源不显示“继承自上级”
- `file_level>=3` 使用“行级继承 + 对象级限制”模型：
  - 每条 `FMP_SCOPE` 通过 `is_inherit_permission` 标识是否继承自上级
  - 顶部黄条只在当前层级“缩小或删除了继承权限”时显示
  - 新增协助者、放大权限不会触发黄条
  - 点击“恢复继承”后，当前对象会恢复为上级完整生效权限集
- 保存成功后，当前弹窗会立即重新拉取最新权限状态。

## Related Data

- 主体文件：`FMP_FILE`
- 权限范围：`FMP_SCOPE`
- 部门来源：`BASIC_JA_DING_DEPT`
- 人员来源：`BASIC_USER`、`BASIC_JA_DING_USER`

- `currentUserKeys` still includes Ding, MPF, ext, and union user keys.
- The `FMP_USER.EXT_USER_ID` lookup now uses session `USER_ID`, so `MPF_USER_ID` can safely store `BASIC_USER.USER_ID`.
