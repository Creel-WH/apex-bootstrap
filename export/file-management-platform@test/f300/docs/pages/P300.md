# P300 - Sub-Platform Management Backend

## Purpose

P300 is the f300 sub-platform management backend list page. It shows existing sub-platforms and provides create, edit, and delete actions.

## Current Behavior

- Lists enabled, non-deleted rows from `STS_SYSTEM`.
- Displays platform code, platform name, business administrators, creation date, remark, and operation buttons.
- Aggregates business administrators from `STS_SCOPE` joined to `BASIC_USER`.
- Filters rendered rows on the client using the keyword input.
- Opens P301 as the create/edit modal.
- Reloads the page after the P301 modal closes so the PL/SQL-rendered list always shows the latest saved data.
- Soft-deletes a sub-platform through on-demand process `P300_DELETE_SUB_PLATFORM`.
- Keeps the search input in DOM for client-side filtering support, but hides it from the refreshed UI.

## Data Dependencies

- `STS_SYSTEM`: platform list and soft-delete target.
- `STS_SYSTEM.REMARK`: persisted remark source for the list page.
- `STS_SCOPE`: business administrator assignment display and cleanup on delete.
- `BASIC_USER`: administrator display names.
