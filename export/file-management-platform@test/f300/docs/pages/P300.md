# P300 - Sub-Platform Management Backend

## Purpose

P300 is the f300 sub-platform management backend list page. It shows existing sub-platforms and provides create, enter, edit, and delete actions.

## Current Behavior

- Lists enabled, non-deleted rows from `STS_SYSTEM`.
- Displays platform code, platform name, business administrators, creation date, and operation buttons.
- Aggregates business administrators from `STS_SCOPE` joined to `BASIC_USER`.
- Filters rendered rows on the client using the keyword input.
- Opens P301 as the create/edit modal.
- Soft-deletes a sub-platform through on-demand process `P300_DELETE_SUB_PLATFORM`.
- Enters the selected sub-platform by calling `SET_CURRENT_SYSTEM`, then redirects to app `299` page `9999` with request `P300_HANDOFF`.

## Handoff Contract

- Target URL: `f?p=299:9999:0:P300_HANDOFF:<DEBUG>:9999:P9999_HANDOFF_USER,P9999_HANDOFF_SYSTEM_ID:<user>,<system_id>`
- User value: `USER_JOB_NUMBER`, falling back to `APP_USER`.
- System value: selected `STS_SYSTEM.SYSTEM_ID`.
- The receiving app is expected to handle `P300_HANDOFF` on page `9999`.

## Data Dependencies

- `STS_SYSTEM`: platform list and soft-delete target.
- `STS_SCOPE`: business administrator assignment display and cleanup on delete.
- `BASIC_USER`: administrator display names.
- Shared APEX process `SET_CURRENT_SYSTEM`: validates and stores selected sub-platform in session state before redirect.
