# P301 - Sub-Platform Maintenance Modal

## Purpose

P301 is the create and edit modal for sub-platform records in f300. It is opened from `P300` and is responsible for collecting the platform name and business administrator assignments.

## Current Behavior

- Opens as a modal dialog from `P300`.
- Supports both create and edit through hidden item `P301_SYSTEM_ID`.
- Collects:
  - `P301_ADMIN_IDS`
  - `P301_REMARK`
- Displays `P301_SYSTEM_NAME` as a read-only generated value.
- Uses a multi-select Popup LOV over `BASIC_USER` for administrator selection.
- Saves through process `P301_SAVE_SUB_PLATFORM`.
- Loads existing values through process `P301_LOAD_SUB_PLATFORM`.

## Visual Contract

- The modal is currently rendered as a single white form card with rounded corners, compact spacing, and a strengthened primary/secondary button hierarchy.
- The administrator field keeps the existing Popup LOV behavior, but selected users render as clearer pill-style tags.
- The remark field is stored in `FMP_SYSTEM.REMARK` and follows the same visual input language as the rest of the modal.
- The page is optimized to visually align with the confirmed backend screenshot while preserving existing business logic.

## Data Dependencies

- `FMP_SYSTEM`: create/update target for sub-platform master data.
- `FMP_FILE`: stores the synchronized top-level root folder for each sub-platform.
- `FMP_SCOPE`: stores business administrator manage scope rows.
- `BASIC_USER`: administrator candidate list and display mapping.
- `JA_UTILS_PKG`: splits stored administrator values during save.
