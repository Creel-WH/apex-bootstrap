# P300 UI Refresh

## Context

- Date: 2026-06-11
- Environment: `file-management-platform@test`
- App: `f300` / APEX app `300`
- Target page: `P300`
- Request: refresh the `P300` list page UI by referencing the provided screenshot and apply several structural display changes.
- Reference image: `E:/PixPin/Temp/PixPin_2026-06-11_10-13-53.png`

## Requested Changes

1. Change the in-page title to `平台列表`, optionally with a similar icon.
2. Hide the search box without deleting it.
3. Change platform code format to `fmp` + primary key id.
4. Add a persisted remark field.
5. Remove the `进入` action button.
6. Refresh typography, colors, spacing, and button styling to better match the reference UI.

## Current Findings

- `P300` is rendered from a custom PL/SQL HTML table in `page_00300.sql`, so visual and column changes can be made directly in the page export without switching report components.
- The current page already owns the title block, search row, and action buttons, so items `1/2/3/5/6` are page-only changes.
- The current `STS_SYSTEM` table initially had no remark-like column, so persisted remark support requires a DB change and matching `P301` maintenance updates.

## Impact Analysis

### Impacted Pages

- `P300` / `page_00300.sql`: primary target.
- `P301` / `page_00301.sql`: extended to maintain the new persisted remark field.

### Impacted DB Objects

- `STS_SYSTEM`: add persisted `REMARK` column.

## Confirmed Decision

- 2026-06-11: confirmed to implement a real persisted remark field.
- Scope therefore includes:
  - DB source update for `STS_SYSTEM.REMARK`
  - runtime DB deployment
  - `P301` create/edit/save/load support
  - `P300` list display support

## Success Criteria

1. `P300` visually aligns more closely with the provided reference image.
2. Title, hidden search, code format, and action column changes behave as requested.
3. `P301` can maintain `STS_SYSTEM.REMARK` end-to-end.
4. Source export, docs, deployment, and browser validation remain in sync.

## Implementation

- Updated `db/tables/sts_system.sql` to include `REMARK`.
- Added idempotent deployment script `db/tables/001_add_sts_system_remark.sql` so the test environment can be patched safely before page import.
- Updated `P301` to add `P301_REMARK`, save it into `STS_SYSTEM.REMARK`, load it back on edit, and increase the modal height for the extra field.
- Refreshed `P300` UI to match the reference direction more closely:
  - header title changed to `平台列表`
  - added a blue icon block beside the title
  - hid the search row via CSS without removing the DOM element
  - changed platform code display to `fmp<system_id>`
  - moved platform name into a secondary line under the code
  - added persisted remark display
  - removed the `进入` action button
  - refreshed table, button, tag, spacing, and color styling
- Updated `docs/browser-functional.json` to validate the new persisted remark flow end-to-end.
- Follow-up fix:
  - the first `P300` deployment failed at runtime with `ORA-12704` because `UNISTR(...)` values were concatenated directly with HTML `VARCHAR2` fragments inside the PL/SQL report block.
  - corrected the affected labels by converting those `UNISTR(...)` values with `to_char(...)` before concatenation, then re-imported `P300`.
