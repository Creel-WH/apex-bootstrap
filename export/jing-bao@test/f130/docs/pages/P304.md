# P304 事件原因关联

## Purpose
- 维护 `原因分析` 与 `事件现象` 的关联关系。
- 支持交互式网格批量新增、编辑、保存。
- 预留模板下载与批量导入框架，等待后续 Excel 模板链接。

## Source
- Lanhu screenshot requirement dated `2026-06-08`
- Reference page: `P141`

## Main Region
- Region type: `Interactive Grid`
- Query source: `TENANT_EVENT_CAUSE_ASSO`
- Tenant filter: `TENANT_ID = :USERTENANT`
- Department filter: `BASE_DEPT_ID = :BASE_DEPT_ID`

## Columns
- `原因分析`
  - Column: `CAUSE_NAME`
  - Editable
  - Required
  - Max length: 20
- `事件现象名称`
  - Column: `PHENOMENON_CODE`
  - Popup LOV sourced from `TENANT_EVENT_PHENOMENON`
  - Supports search
  - Required
- `事件现象code`
  - Column: `PHENOMENON_CODE_DISPLAY`
  - Read-only display
  - Auto-filled from the selected `事件现象名称`
- `备注`
  - Column: `REMARK`
  - Optional
  - Max length: 20

## Buttons
- `保存`
  - Uses standard IG DML
- `模板下载`
  - Current behavior: placeholder prompt
  - Pending real template URL
- `批量导入`
  - Toggles upload/preview framework

## Batch Import
- Upload type: `.xlsx`
- Preview columns:
  - `原因分析`
  - `事件现象名称`
  - `备注`
- Current import behavior:
  - Resolves phenomenon name to `TENANT_EVENT_PHENOMENON.CODE`
  - Merges rows into `TENANT_EVENT_CAUSE_ASSO`
  - Updates remark for existing relation rows
